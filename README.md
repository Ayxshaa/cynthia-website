# Cynthia Website 🎤✨

A visually dynamic tribute website built using **GSAP** animations and *Javascript**, dedicated to the artist **Cynthia**.

## 🚀 Live Site

🔗 [Visit the Cynthia Website](https://ayxshaa.github.io/cynthia-website/)

---

## 📌 About

This project is a smooth-scrolling, animated website honoring the artist **Cynthia**. The layout is inspired by modern music artist portfolios with a touch of elegance and motion.

It was made with:
- ✨ **GSAP (GreenSock Animation Platform)** for animations
- ⚛️ **JAVASCRIPT** for the component-based architecture
- 🎨 **Custom styling** using CSS

## 🛠️ Built With

- **HTML5 & CSS3** – Layout and styling
